🔍 Cari Pertanyaan / Istilah:

1. GridView (Halaman Kota)

Q: Apa itu GridView.count dan bagaimana cara kerjanya di kode kita?

Jawaban Simpel: GridView.count adalah widget untuk menampilkan item secara berpetak (grid) mirip galeri foto.

Di kode kita:

  • crossAxisCount: 2 artinya 2 kolom ke samping.
  • Isinya berupa daftar item (5 kecamatan di Kupang) yang masing-masing punya gambar, nama, dan tombol "Detail".
💡 Analogi: Seperti rak sepatu yang disusun 2 baris ke samping secara rapi.
Q: Bagaimana cara memanggil GalleryGrid di halaman KotaPage?

Jawaban Simpel: Sangat mudah, tinggal dipasang langsung di dalam body Scaffold.

class KotaPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: _buildAppBar(context),
      body: const GalleryGrid(), // <-- Dipanggil di sini
    );
  }
}

2. Sidebar (Halaman Desa)

Q: Bagaimana cara membuat Sidebar di sebelah kiri?

Jawaban Simpel: Kita buat class khusus bernama AppSidebar.

Strukturnya: Container warna biru dengan lebar 150, isinya Column yang berisi beberapa TextButton (untuk 5 kelurahan).

class AppSidebar extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Container(
      width: 150,
      color: Colors.blue,
      child: Column(
        children: [
          TextButton(onPressed: ..., child: Text("Kel. Namosain")),
          // ... kelurahan lainnya
        ],
      ),
    );
  }
}
Q: Bagaimana cara menggabungkan Sidebar dan Konten di kanan?

Jawaban Simpel: Pakai widget Row! Karena Row menyusun ke samping:

  • Anak pertama: AppSidebar() (lebar 150).
  • Anak kedua: Expanded(child: Center(child: Text(...))) (memakai sisa layar di sebelah kanan).
💡 Analogi: Layar dibagi dua: sebelah kiri laci menu (sidebar), sebelah kanan meja kerja utama (konten).

3. Navigasi & MenuButton

Q: Bagaimana cara kerja pindah halaman di aplikasi ini?

Jawaban Simpel: Kita pakai perintah Navigator.push(...).

Agar transisinya instan tanpa animasi (sesuai aturan tugas), kita bungkus dalam fungsi bantuan pushNoAnim() yang menggunakan PageRouteBuilder dengan durasi nol.

void pushNoAnim(BuildContext context, Widget page) {
  Navigator.push(
    context,
    PageRouteBuilder(
      pageBuilder: (context, anim1, anim2) => page,
      transitionsBuilder: (context, anim1, anim2, child) => child, // Tanpa animasi
      transitionDuration: Duration.zero,
    ),
  );
}
Q: Apa itu MenuButton dan di mana letaknya?

Jawaban Simpel: MenuButton adalah tombol khusus buatan kita sendiri untuk menu bar atas (Home | Desa | Kota | About US).

Diletakkan di dalam AppBar menggunakan Row agar posisinya berjajar rapi ke samping.

4. Gambar & Data Kota Kupang

Q: Bagaimana cara menampilkan gambar dari folder lokal?

Jawaban Simpel: Pakai Image.asset("gambar/nama_file.jpg", height: 100).

Syaratnya: folder gambar/ harus didaftarkan di file pubspec.yaml pada bagian assets: - gambar/.

Q: Kenapa kota yang digunakan adalah Kota Kupang (NTT)?

Jawaban Simpel: Karena instruksi tugas mengharuskan nama kota nyata (bukan A, B, C). Kami memilih kecamatan-kecamatan di Kota Kupang, NTT (seperti Kelapa Lima, Maulafa, Alak, dll.) beserta kelurahannya.

5. 💡 Tips Penting Saat Ujian Lisan Individual

  • Jangan panik: Pahami konsep dasarnya saja (Mana GridView? Mana Sidebar? Bagaimana cara pindah halaman?).
  • Pahami file main.dart: Ingat bahwa semua kode digabung dalam 1 file ini.
  • Tahu fungsi Widget Utama:
    • Scaffold = Kerangka dasar halaman (ada AppBar & Body).
    • Column = Susun ke bawah.
    • Row = Susun ke samping.
    • Expanded = Mengisi sisa ruang kosong.
